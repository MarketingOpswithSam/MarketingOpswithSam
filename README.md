# Hi, I'm Sam

I work in marketing ops. I build the plumbing behind marketing: the automations, tracking and workflows that make campaigns measurable and keep teams from doing the same task by hand twice.

I write about it at **[marketingopswithsam.com](https://marketingopswithsam.com)** and send a short newsletter on marketing ops and automation.

## What I'm working on

- Getting small sites found in Google and in AI answers (ChatGPT, Perplexity, Copilot)
- Automating the repetitive middle of marketing work: reporting, QA, publishing
- Turning workflows into diagrams people can actually read

## Open-source tools

Small, dependency-free, and made for people who run campaigns rather than write software.

| Repo | What it does |
| --- | --- |
| [aeo-audit](https://github.com/MarketingOpswithSam/aeo-audit) | Checks a live page for SEO and answer-engine basics: titles, canonicals, schema, alt text, AI crawler access, llms.txt |
| [indexnow-submit](https://github.com/MarketingOpswithSam/indexnow-submit) | Pings Bing and other engines the moment you publish, so pages get indexed in hours |
| [utm-toolkit](https://github.com/MarketingOpswithSam/utm-toolkit) | A UTM naming convention plus a CLI that builds clean links and flags bad ones |
| [diagram-forge](https://github.com/MarketingOpswithSam/diagram-forge) | Turns a funnel, attribution model or automation into a diagram that makes its point |
